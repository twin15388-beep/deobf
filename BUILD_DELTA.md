# Расхождение сборок: дамп `Текстовый документ (2).txt` против артефакта

Проверка после честного сравнения (раскодированы `\u{203A}`, `\ddd`, `\n` и т.д. —
иначе сравнение «сырой текст против рантайма» даёт ложные расхождения).

## Что сравнивалось

| | артефакт `ouroboros_ps2 (1).luau` | дамп `Текстовый документ (2).txt` |
|---|---|---|
| записей | 6641 (пул `cKb[136]`) | 5895 |
| строковых значений | 3286 | 3158 |
| общих строк | — | **2846** (86% строк артефакта) |
| «мусорных» имён `[a-z]{4,12}` | 737 | 617 |
| из них совпадают | — | **347** |

Ключевой признак: обфускатор генерирует случайные имена заново на каждой сборке.
347 из 617 совпали, но 270 «мусорных» имён и ~390 имён из артефакта в дампе
отсутствуют → **дамп снят с другой сборки** (не с нашего артефакта).

## Что в дампе есть, а в артефакте нет

Осмысленные имена (всё остальное — мусорные идентификаторы):

| имя | где в дампе | вывод |
|---|---|---|
| `antiTamper` | индекс 1818, рядом `Clock`, `InfiniteStamina` | в артефакте такой строки нет вообще → в живой сборке есть модуль защиты от тамперинга |
| `Fusion` | индекс 129, рядом `waitSample`, `POSITION_TYPES`, `modifiers` | новая позиция/режим движения (в артефакте `POSITION_TYPES` = Behind, Below, Inside, Above, Orbit, Front, Side) |
| `Warp` | индекс 1826, рядом `Max Stamina`, `Chest` | там же — вторая новая позиция/режим |

Проверено грепом по артефакту: `Fusion`, `Warp`, `antiTamper` — 0 вхождений
(в т.ч. через escape-последовательности).

## Что это значит для реконструкции

* Логика, которую мы переносим (экипировка, скиллы, парирование, лут/квесты),
  опирается на строки и F-слоты, которые в дампе есть и совпадают по значению —
  перенос остаётся валидным.
* Но живую сборку наш артефакт не покрывает: в ней есть минимум два новых
  режима (`Fusion`, `Warp`) и анти-тампер. Если игра сейчас именно такая,
  часть настроек в меню (Position Type / Movement Type) в артефакте описана
  не полностью.
* Индексы пулов двух сборок несовместимы (как и было известно ранее) —
  сопоставление возможно только по значениям строк.

## Что нужно, чтобы устранить расхождение

Прислать **сам файл скрипта** той сборки, которую запускаешь (не дамп, а `.lua`/`.luau`,
который вставляешь в исполнитель). Тогда `tools/pool_map.py` построит точную карту
пула для живой сборки, а `tools/api_map.py` — актуальный список настроек, и
реконструкция пойдёт 1:1 по живой версии.
