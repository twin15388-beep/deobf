# Читаемые результаты деобфускации Roblox Lua

Здесь оставлены только **содержательные текстовые результаты**. Файлы названы по заявленной игре. Они предназначены **для чтения, не для запуска**: безопасность, авторство, работа в нынешнем Roblox и поведенческая эквивалентность не проверялись. Полный список источников, закреплённые коммиты и SHA-256 — в [новом отчёте о десяти играх](../reports/roblox-sources-2026-10-18.md) и [JSON](../reports/roblox-sources-2026-10-18.json).

## Новое: встроенный Lua раскрыт целиком (2 входа, 3 отдельных chunks)

| Заявленная игра | Открыть | Предел результата |
| --- | --- | --- |
| **Ninja Masters** | [Ninja Masters.decoded.lua](Ninja%20Masters.decoded.lua) | Точные **5 134 байта** единственного аргумента `loadstring` с десятичными Lua-экранированиями; не декомпиляция VM. |
| **Tower Battles** | [Tower Battles.part1.decoded.lua](Tower%20Battles.part1.decoded.lua) · [Tower Battles.part2.decoded.lua](Tower%20Battles.part2.decoded.lua) | Точные **906 и 3 072 байта** двух разных аргументов `loadstring`. В исходной обёртке между ними **`wait(2)`**. Первая часть — список башен, вторая — GUI; локальные области вызовов раздельны. |

Для всех трёх частей: `luaparser 4.2.0` и `Lua 5.1 luac -p` — **синтаксис проходит**. Это не тест логики. Исходные обёртки, SHA-256 и офлайн-декодер [`decode_decimal_loadstring.py`](../scripts/decode_decimal_loadstring.py) приведены в [отчёте](../reports/roblox-sources-2026-10-18.md).

## Что удалено как непригодное для папки с исходниками

При очистке удалены девять ранее опубликованных бинарных `.container.bin`/`.candidate.bin`, оставшиеся VM под видом `.lua/.luau`, диагностические `.analysis.json` и два файла **чужого экрана ключа**, ошибочно рекламируемого как GPO-автофарм. Их исторические размеры и SHA-256 остались в полях `removed_artifacts` JSON-отчётов; **не ищите их по старым ссылкам**. Сырые защищённые входы и восемь [уже открытых исходников других игр](../reports/roblox-sources-2026-10-18.md) не перепубликованы здесь под видом результата.

> Публичность стороннего кода не равна разрешению на его повторное распространение. Производные файлы опубликованы по запросу владельца репозитория с указанием upstream; права/лицензии авторов исходных скриптов не установлены. Не запускайте результат без независимой проверки.
