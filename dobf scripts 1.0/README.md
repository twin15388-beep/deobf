# dobf scripts 1.0

Статические результаты анализа Roblox-скриптов. **Полностью восстановленных и проверенных в Roblox исходников нет**: из 10 файлов — 5 частичных результатов и 5 неудач. Эти файлы не следует запускать: в них могут оставаться VM, сетевые загрузчики и неизвестная логика.

## Сначала открыть — восстановлена структура кода

| Игра | Файл | Что получилось |
| --- | --- | --- |
| **Grand Piece Online** | [01-gpo-xtrey-prometheus.partial.luau](01-gpo-xtrey-prometheus.partial.luau) | Статически построена структура 22 обнаруженных функций Prometheus/WeAreDevs VM, 535 констант. Имена/обвязка остаются; эквивалентность исходной программе не проверена. |
| **Untitled Boxing Game** | [08-untitled-boxing-prometheus.partial.luau](08-untitled-boxing-prometheus.partial.luau) | Структура 15 обнаруженных функций, 294 константы. Это не доказательство полной деобфускации или работоспособности. |

Промежуточные данные для проверки: [GPO IR](01-gpo-xtrey-prometheus.ir.json) и [Boxing IR](08-untitled-boxing-prometheus.ir.json).

## Только частичная распаковка — не готовые скрипты

- [Grow a Garden — внутренний Luau VM](04-grow-garden-v14-inner-vm.luau): снят внешний слой Luraph v14.4.1, прикладной код всё ещё виртуализирован.
- [DOORS — развёрнутый диспетчер VM](05-doors-prometheus-vm-deflattened.lua): константы и управление частично восстановлены, исходная логика не поднята.
- [GPO Luraph v13.5.8 — бинарный контейнер](03-gpo-luis-v13-container.bin): это **не Lua-код**, пригоден только для дальнейшего анализа.

## Не считать GPO-автофармом

У кандидата из RScripts после замены 922 строковых вызовов обнаружился **интерфейс проверки ключа**, а не заявленный GPO-автофарм. Он **не входит в десятку**: [декодированные литералы](excluded-dilleron-key-ui.xor.lua) · [форматированная версия](excluded-dilleron-key-ui.formatted.lua).

Для GPOKAIZEN, Blade Ball, Arcane Odyssey, Blox Fruits и Fruit Battlegrounds код не восстановлен; под видом результата их исходные обфусцированные файлы сюда не добавлены.

[Подробный отчёт](../reports/roblox-batch-2026-10-18.md) · [Коммиты источников и SHA-256 каждого файла](../reports/roblox-batch-2026-10-18.json). Имена файлов и содержимое в этой папке идентичны ранее полученным локальным результатам. **Steal an Egg не анализировался; Pastefy/API не использовались; защищённые скрипты не исполнялись.**

> Производные файлы содержат чужой код из публичных репозиториев. Публичная доступность исходника не равна лицензии на повторное распространение; права и условия исходных авторов не установлены. Публикация здесь сделана по запросу владельца этого репозитория и не даёт дополнительной лицензии на код.
