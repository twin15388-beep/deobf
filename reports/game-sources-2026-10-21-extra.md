# Дополнительный поиск крупных игровых Luau — 21 октября 2026

**Итог этого прохода: два новых содержательных файла, всего 57 в [`dobf scripts 1.0/`](../dobf%20scripts%201.0/README.md).** Один — статическое раскрытие собственной таблицы строк Anime War RNG; второй — крупный **открытый исходник** Deepwoken `(src)`, не деобфускация. Игровые скрипты **не запускались в Roblox**; серверные действия, полная совместимость с текущими версиями игр и безопасность сторонних зависимостей не доказаны. ## 1. Anime War RNG — [WaveHub, статически раскрытый код](../dobf%20scripts%201.0/Anime%20War%20RNG%20-%20WaveHub.lua)

**Происхождение:** MIT [`wavechayakon/WaveHub@198b5d26877c44b0533b6c3f1826a87515d59faf/games/anime-war-rng.lua`](https://github.com/wavechayakon/WaveHub/blob/198b5d26877c44b0533b6c3f1826a87515d59faf/games/anime-war-rng.lua), SHA-256 входа `7377afb9d1b8cc7d6390b504080a4f8cddb5f04bb2373c7179dbca4397f4f643`. Статус: **все обнаруженные вызовы конкретного строкового шифра раскрыты**, исходное тело программы после дешифратора сохранено; **это не восстановление внешней библиотеки и не тест в Roblox**. SHA-256 результата `92354aa770eaf8ff8a9c6db397b0af280b415ab22667af6bb2f3f98b11af3b96`.

- Оригинал: 161 322 байта / 4 777 строк. Декодер раскрывает **607/607** элементов таблицы (8 299 байт содержимого) и подставляет их в **1 070** числовых вызовов. Оставшихся обращений к этому дешифратору в игровом теле нет. Алгоритм — заданный автором алфавит Base64, ключ по индексу, побайтовое вычитание `key + 31·position + (17·index mod 251) + (position² mod 127)` по модулю 256. Никакого игрового кода при раскрытии не исполнялось.
- Для **независимой проверки значений** запущены в локальном Luau **только отрезанная от gameplay таблица, исходная функция дешифратора и сгенерированные строковые литералы**: все 607 строк побайтово совпали с Python-вычислением и со вставленными Luau-литералами. Хеш индекс+длина+байты таблицы: `422321a3b2d44518208e1ad91d08bb9bdaa0f1afbabc44569e4a2dde38849b4d`. Отдельно `luau-compile --null` принял опубликованный результат. Это проверка строк и синтаксиса, **не** эквивалентности работы Roblox.
- Результат: **3 553 строки с 32-строчным заголовком**; собственное тело — 3 521 строка / 127 638 байт. В теле строки **1–402** — общий загрузчик/оболочка WaveHub, **403–3521** — функция `BuildAnimeWarRNG` и её вызов (3 119 строк, UI-кнопки и игровая логика перемежаются). `WindUI` (`Footagesus/WindUI`) **не включён**: при запуске модуль скачивает и исполняет `main.lua` с GitHub releases, включая изменяемый `latest`. Отдельное количество строк этой библиотеки неизвестно; **3,5 тыс. строк результата нельзя считать размером всего UI**.
- Игровой адрес — `PlaceId 79908803570376`, хотя общая оболочка до функции игры пишет `ScriptInfo.Game = "Universal"`. Внутри именно игры известны **83 уникальных имени remotes**, **21 подписка `watch(...)`** на входящие события, множество игровых callback. Перечень имён в таблице — это предположения скрипта: отдельная кнопка сверяет их наличие в Roblox, проверка нами не проводилась.

**Оставшиеся зависимости и риски:** модуль **не автономен**: нужны глобалы/`sharedRequire`, классы, конфигурация и UI оригинального Aztup Hub. Стартовый запрос списка модераторов на сторонний сайт с `websiteKey` и две загрузки MP3 через `AudioPlayer` **не удалены**; остаются опциональные webhook-настройки для ores/Animal King. Очищена **только эта игровая Lua-часть**; другие файлы оригинального Aztup Hub могут вести собственную аналитику и не проходили полный аудит. Зависимость от сторонних запросов и версий Roblox сохраняется. Этот вариант содержательно отличается от уже опубликованного маленького [`Deepwoken - Aztup Race Changer (src)`](../dobf%20scripts%201.0/Deepwoken%20-%20Aztup%20Race%20Changer%20%28src%29.lua): тот меняет локальную косметику, **не** расу на сервере.

**Следствие для оценки «UI 6 тыс.+»:** длина защищённого blob, объём открытого `src` и количество строк полученной программы — **разные величины**. Для защищённых Luraph/MoonSec/LUAST точного размера восстановленного UI вообще нет — потому что **восстановленного исходника нет**. Это не доказательство, что восстановление когда-либо будет полным.

## Воспроизведение и предел инструментов

```bash
# Сначала получить закреплённые MIT-исходники из GitHub git clone (не через site API и не pastefy.app).
python -m scripts.decode_wavehub_anime_war_rng /path/to/WaveHub/games/anime-war-rng.lua 'dobf scripts 1.0/Anime War RNG - WaveHub.lua'
python -m scripts.verify_wavehub_strings /path/to/WaveHub/games/anime-war-rng.lua /path/to/luau
python -m scripts.sanitize_aztup_deepwoken /path/to/Aztup-Hub-V3/files/games/DeepWoken.lua 'dobf scripts 1.0/Deepwoken - Aztup main (src).lua'
python scripts/verify_results.py
python -m unittest tests.test_wavehub_anime_war_rng tests.test_aztup_deepwoken_sanitizer
luau-compile --null 'dobf scripts 1.0/Anime War RNG - WaveHub.lua'
luau-compile --null 'dobf scripts 1.0/Deepwoken - Aztup main (src).lua'
```

`verify_wavehub_strings.py` создаёт **временный файл исключительно с исходным строковым декодером**, не запускает игровой Lua. Остальные команды также не исполняют игровую программу; компиляция не подтверждает прохождение античита и серверные результаты. Для MoonSec V3 нет доступного локально проверенного lifter; Luraph v14.9 и LUAST остаются нерешёнными. Другие приоритеты (Trident Survival, Demonfall, Anime Vanguards, VV Ultimatum, отдельная игра Illegal Sorcer, полноценный King Legacy) **не получили в этом проходе нового проверяемого игрового Lua**: часть найденных вариантов — нелицензированные защищённые файлы либо только загрузчики. [Предыдущие 55 результатов и их ограничения](game-sources-2026-10-21-followup.md) остаются в силе.
