## Практический следующий шаг

1. Прочитать [../AGENTS.md](../AGENTS.md), оба последних отчёта, проверить `git status --short --branch`, `git log -1` и актуальный [PR #1](https://github.com/twin15388-beep/deobf/pull/1). Если другая AI-среда выдала *свою* ветку, следовать её правилам, а не принудительно переключаться на ветку из этой памятки.
2. Искать прежде всего **защищённое тело игры**, доступное законно, с правом на повторное распространение. Для Luarmor/Jnkie без разрешённого локального HTTP-ответа есть только loader/SDK: ни `inspect_api_delivery.py`, ни изменение URL не создадут серверный исходник. Карточки RScripts/ScriptBlox — ориентиры, GitHub-поиск — для метаданных, тела разрешённых репозиториев — через `git clone` закреплённого коммита. **Не использовать Pastefy или API для получения скриптов и не обходить ключи.**
3. Если подходящий вход найден, применять инструмент **к его реальной версии защиты**, делать статическую/изолированную проверку игровых функций и аргументов, фиксировать SHA-256 входа/выхода, лицензию, добавленные составителем изменения и честную границу полноты. При невозможности восстановления не создавать файл «для счётчика»; описать отрицательный результат. При новом игровом `.lua` создать отдельный JSON-манифест, внести его в `SOURCE_REPORTS` у [`verify_results.py`](../scripts/verify_results.py), обновить каталожный README/счётчик, написать тесты и отчёт.
4. Минимум перед передачей: `python3 -m unittest discover -s tests -p 'test_*.py'` (**на снимке 103 теста**, два пропуска без интерпретаторов Lua/Luau); `python3 scripts/verify_results.py` (**67 файлов**, 9 манифестов); `python3 scripts/check_decoder_output.py <вывод декодера>` перед любой публикацией; `python3 scripts/verify_sources.py` (**46 архивов**); `node --test tests/test_psu_fixed_calls.mjs` (**1 тест**); `git diff --check`. Для Lua-проверок сначала собери интерпретатор: `python3 scripts/prepare_lua51.py local-results/lua51`, затем запускай `tests/test_*.lua` через него и передавай `LUA51=local-results/lua51/lua5.1` в unittest. Для Luau-проверки: `python3 scripts/prepare_luau.py local-results/luau` (CMake ставится колесом `pip3 install --target local-results/pylibs cmake`) и затем `local-results/luau/luau-compile --text <файл>`. Roblox не запускался. Если меняется игровой код, добавь профильные Lua-тесты, их список в [`tests/`](../tests/).
5. После прохода **обновить эту памятку**: дату, фактический счётчик, новые входы/результаты/тупики, хеши и проверки. Не коммитить HAR, секреты, чужие большие защищённые образцы, сырые выгрузки, бинарники и `node_modules`.
