# Ещё десять игр: два извлечённых payload и восемь найденных открытых исходников

18 октября 2026 г. Это **не десять успешных деобфускаций**. Для **двух новых входов** из разных игр удалось без исполнения Lua полностью раскрыть *встроенные в файл* Lua-строки; для **восьми других игр** найдены уже открытые исходники, которые **не являются** результатами обработки защищённых файлов. Итого — десять разных игр с доступным текстом скриптов, но только два входа со статически раскрытым слоем. Ни один скрипт не испытывался в Roblox. Точные коммиты, размеры и SHA-256 — в [JSON-отчёте](roblox-sources-2026-10-18.json).

## Действительно извлечено из обёрток

1. **Ninja Masters:** [исходный защищённый файл `Autofarm_NinjaMasters.lua`](https://github.com/retpirato/Roblox-Scripts/blob/2a0461de8fed66b5d63b7c0a09443ba8cf6f6a3a/Autofarm_NinjaMasters.lua) → [Ninja Masters.decoded.lua](../dobf%20scripts%201.0/Ninja%20Masters.decoded.lua), **5 134 байта**. Обёртка целиком состоит из одного вызова `loadstring` с десятичными Lua-экранированиями; восстановлены точные байты аргумента. SHA-256 входа `064a59763654f5ede4c193e549a679a66b1c96d359afce4039c33a381fa1cf9d`, результата `094b460b2763dac1a1e4570d856f9f0c4e2937b5032c30c73fdcedd80cb892c9`.
2. **Tower Battles:** [исходный `Tower Battles GUI.lua`](https://github.com/retpirato/Roblox-Scripts/blob/2a0461de8fed66b5d63b7c0a09443ba8cf6f6a3a/Tower%20Battles%20GUI.lua) → [часть 1 — список башен](../dobf%20scripts%201.0/Tower%20Battles.part1.decoded.lua), **906 байт**, затем в оригинале стоит `wait(2)`, затем [часть 2 — GUI](../dobf%20scripts%201.0/Tower%20Battles.part2.decoded.lua), **3 072 байта**. SHA-256 входа `87297397d926196e329ab412900a1add4d00839a917371524dd1162327051e88`. Оба `loadstring` — **самостоятельные Lua chunks с разными областями локальных переменных**: объединять их в один якобы эквивалентный запускаемый файл нельзя.

Все три фрагмента прошли статический разбор `luaparser 4.2.0` и `Lua 5.1 luac -p`. Это доказывает синтаксис, а не безопасность/работоспособность/эквивалентность реальному поведению игры. Сами имена игр подтверждены названием файла и признаками кода, но выполнение в актуальном Roblox не подтверждено. Декодер [`decode_decimal_loadstring.py`](../scripts/decode_decimal_loadstring.py) **строго проверяет всю обёртку**, отвергает посторонний код и числовые escape вне диапазона байта; он не выполняет Lua и не обращается к сети. Для воспроизведения возьмите исходные файлы с указанных коммитов, сверьте SHA-256 и вызовите `python3 scripts/decode_decimal_loadstring.py INPUT --output-dir OUTPUT --name 'Ninja Masters'` (или `'Tower Battles'`).

## Что ещё пробовали и почему не засчитали

- **Ещё 10 обфусцированных входов** проверены PSU-lift: девять дали Lua 5.1 bytecode без неизвестных инструкций, один не прошёл лимит регистров. Из девяти восемь декомпилируются только в диагностический псевдокод: Farm Yard Simulator, Money Simulator X, Pet Simulator X Power Calculator, Printing Simulator, PapierLP Hub, Blox Fruits (`SenpaiUser`), Pet Simulator X autoCollection и Senter. Это не публикуемые игровые исходники. Десятый вход — `PapierLP Notifier` — дал синтаксический Lua, но содержит **секрет Discord webhook** и не имеет установленной игры: файл/секрет не публиковались, webhook не вызывался. Старый образец SeaHub использовался только как контроль и в эти десять не входит. Пины всех входов, результаты и исключения — в [JSON](roblox-sources-2026-10-18.json); секрет там отсутствует.
- В `scriptsomega/scripts` 13 выборочно раскрытых Base64-обёрток разных игровых названий оказались почти одинаковыми **экранами ключа Delta X**, а не 13 независимыми игровыми скриптами. Их не засчитывали. Никакие вторичные URLs не открывались.
- В `HamieXD/luast-deobfuscator` рядом лежат оригинал и защищённый Level 1 для Tapping Simulator. Пин `luast_deob.py v0.3.0` при вызове `deobfuscate -o` сообщает «successfully written», но **не записывает выходной Lua-файл**: получены только аналитические таблицы (140 элементов, 14 функций). Нельзя представлять соседний исходный образец как его результат.

## Очистка опубликованной папки

Из `dobf scripts 1.0` убраны **девять ранее опубликованных** непрозрачных бинарных контейнеров/кандидатов, файлов с оставшейся VM, диагностических JSON и двух экранов ключа, не относящихся к GPO (всего **1 293 743 байта**). Остались три ранее полезных частичных Lua-результата и три новых точно раскрытых фрагмента. Исторические размеры/SHA-256 удалённых файлов сохранены в `removed_artifacts` старых JSON-отчётов; оценки старых попыток не переписаны как успехи. После проверки совпадения SHA-256 удалены также 12 дублирующих рабочих копий из неотслеживаемой папки `local-results/`; три полезных частичных результата остались в опубликованной папке. ZIP с инструментами не удалялись: пользователь просил сохранить разнообразие деобфускаторов.

**Безопасность и пределы:** защищённый Lua не выполнялся; Roblox, Pastefy, RScripts raw/API и доступы к API для получения скриптов не применялись. **Steal an Egg не исследовался.** Эти скрипты не рекомендуется запускать. Название и наличие открытого исходника сами по себе не подтверждают работу в нынешней версии игры.
