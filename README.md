# Roblox Lua / Luau deobfuscators

**Подключаете другого ИИ для продолжения?** Сначала дайте ему прочитать [AGENTS.md](AGENTS.md) и [памятку с состоянием и готовым запросом](reports/AI-HANDOFF.md). В Git сохранены инструкции и результаты, а не веса нейросети; пароль или Roblox-ключ для передачи работы не нужен.

Коллекция **исходников** инструментов для анализа обфусцированных Roblox Lua/Luau-скриптов. Архивы снимались 18 октября 2026 года; работа каждого инструмента со всеми версиями защиты не гарантируется.

Три новых полных статических раскрытия WeAreDevs/WAD из MIT-входов: [Slap Battles - Tryhard AI Demo](dobf%20scripts%201.0/Slap%20Battles%20-%20Tryhard%20AI%20Demo.lua) (1 149 строк авто-боя; найдено, что оригинал работает только в истёкшем окне времени 2025-11-15…2025-11-22 UTC), [Prison Life - volmaks ESP Freecam](dobf%20scripts%201.0/Prison%20Life%20-%20volmaks%20ESP%20Freecam.lua) (1 090 строк `Drawing`-ESP и свободной камеры, ни одного remote, удалена одна строка `goto` без метки) и [Work at a Pizza Place - Order4](dobf%20scripts%201.0/Work%20at%20a%20Pizza%20Place%20-%20Order4.lua) (1 244 строки с remote `GiveBonus`/`EmployeeOfTheDay`/`OrderComplete`). Исправлен [офлайн-адаптер локальных ответов](scripts/inspect_api_delivery.py): файл с Luarmor-ссылками **и реальными игровыми вызовами** больше не обозначается `loader_only`; Jnkie SDK рядом с VM тоже не считается одним лишь loader. [Новый ограниченный инспектор Luraph v14.6](scripts/inspect_luraph_envelope.py) статически снял две оболочки из локального образца с Jnkie SDK, но получил лишь **интерпретатор VM (71 877 байт) и её байткод (454 019 байт)**, не игровой исходник. Ключи, API выдачи скриптов и Pastefy не использовали; образец из репозитория без обнаруженной лицензии не опубликован. [Ошибки, попытки, хеши, функции уже вложенного Blox Fruits-выхода и ограничения](reports/offline-luarmor-jnkie-2026-10-22.md) · [проверенные ранее кандидаты](reports/api-delivery-2026-10-21.md). [Сканер констант IB2-fork](scripts/inspect_ib2_fork_constants.py) по Lone Survival остаётся статической диагностикой, не игровой декомпиляцией.

**Ограничения:** исключённый `unluac.jar` требуется для части функций Luraph-инструмента Tony Bolivar; исключённые Lua 5.1 бинарники могут понадобиться Epimetheus (можно установить Lua отдельно). Также удалены скомпилированные Luau/bf для Wynfuscate и Mcdofries: при необходимости их надо получать/собирать отдельно. Инструментам MoonVeil тоже нужны официальные Luau runtime/compiler, которые в ZIP не включены. У некоторых других проектов есть внешние зависимости — смотрите их README. MoonDumper/moonsecdumper предполагают выполнение *сгенерированного* Lua; Wynfuscate/Mcdofries предлагают динамический анализ. Никогда не запускайте неизвестный скрипт без изоляции и разрешения владельца; Discord-боты могут передавать загруженный код стороннему сервису. Часть инструментов позже проверена на конкретных входах: [отчёт от 19 октября](reports/game-recovery-2026-10-19.md) и [дополнение от 21 октября](reports/game-recovery-2026-10-21.md), а также [следующий проход](reports/game-recovery-2026-10-21-followup.md), включая негативные результаты. Для диагностической обработки PSU отдельно установлен npm-пакет `unluac-js@1.4.4`; он не включён в архив исходников Rust. Исходники `memcpython/PSU-Deobfuscator` и `viruscamp/luadec` без явной корневой лицензии здесь не скопированы, хотя локально исследовались/собирались. Полные защищённые Roblox-скрипты не исполнялись: прежде шесть отделённых GPO-прототипов проверены на макетах без сети (два через синтетических родителей с upvalue); восемь выделенных прототипов **исправленного** Zero Academia bytecode сравнены с частичным модулем в 28 mock-сценариях; десять выбранных детей **исправленного** Anime Fighters — в 20 сценариях. Для воспроизводимого исправления CALL — [локальные постпроходы над IR PSU](scripts/lift_psu_multireturn.mjs) и [для Anime Fighters](scripts/lift_psu_fixed_calls.mjs); полные декомпиляции по-прежнему содержат ошибки и не опубликованы.

Проверить целостность новых архивов без запуска стороннего кода:

```bash
python3 scripts/verify_sources.py
python3 scripts/verify_results.py  # SHA-256 опубликованных результатов, не проверка их поведения
```
